Claude Code Workshop is a 3-hour training for developers who already use
Claude Code and want to go beyond the default usage. The format alternates
short theory sessions and practical exercises.

The program covers the foundations and internals of Claude Code, then its
customization options. Two hands-on blocks let each participant build their
own skill and package a subagent as a plugin.

Workshop structure (3 hours):
- **Foundations and internals**: how Claude Code works, context and memory
  model, command surface.
- **Customization**: slash commands, settings, hooks, skills.
- **Subagents and plugins**: building focused agents and packaging them.
- **Hands-on labs**: two guided practice blocks.

For reference, I built the slides with [Slidev](https://sli.dev/). The full
material (slides, exercises, notes) is open-source. You are welcome to
reshare and adapt this training for your teams, as long as you credit the
source.
