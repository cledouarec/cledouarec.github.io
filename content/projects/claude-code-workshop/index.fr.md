Claude Code Workshop est un atelier de 3 heures pour les développeurs qui
utilisent déjà Claude Code et souhaitent aller au-delà de l'usage par défaut.
Le format alterne courtes séquences théoriques et exercices pratiques.

Le programme couvre les fondamentaux et le fonctionnement interne de Claude
Code, puis ses options de personnalisation. Deux blocs de pratique permettent à
chacun de construire son propre skill et d'empaqueter un subagent en plugin.

Déroulé de l'atelier (3 heures) :
- **Fondamentaux et internes** : fonctionnement de Claude Code, modèle de
  contexte et de mémoire, surface de commandes.
- **Personnalisation** : slash commands, settings, hooks, skills.
- **Subagents et plugins** : conception d'agents spécialisés et packaging.
- **Travaux pratiques** : deux blocs guidés.

Pour info, j'ai réalisé les slides avec [Slidev](https://sli.dev/). L'ensemble
du matériel (slides, exercices, notes) est open-source. Vous pouvez repartager
et adapter cette formation pour vos équipes, à condition d'en citer la source.
